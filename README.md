# 📖 About This Book

This repository is designed as a **complete learning book for Embedded Systems and IoT**.

It starts from the absolute basics:

> **What is a computer?**

and gradually moves toward:

> **How do I build a complete connected IoT system?**

The guide covers:

- 🧠 Embedded Systems
- 🔌 Microcontrollers
- 💻 Microprocessors
- 🖥️ Microcomputers / SBCs
- 🔵 Arduino
- 🟢 ESP8266 / ESP32
- 🍓 Raspberry Pi
- ⚡ GPIO
- 📈 PWM
- 🔢 ADC / DAC
- 🔄 UART / SPI / I²C
- 📡 Wi-Fi / Bluetooth
- 🌐 Internet of Things
- ☁️ Cloud systems
- 📬 MQTT
- 🔗 HTTP APIs
- 🐍 Python
- 💻 Firmware
- 🔧 Hardware + Software integration
- 🤖 Practical projects
